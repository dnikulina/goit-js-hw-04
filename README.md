# JavaScript Objects & Methods

![JavaScript](https://img.shields.io/badge/JavaScript-ES6-yellow?style=flat-square&logo=javascript&logoColor=black)

## Overview

This repository contains JavaScript exercises focused on objects, collections of objects, object methods, and calculations using structured data.

## Tech Stack

- JavaScript
- HTML
- Git & GitHub

## Tasks

### Container Capacity Check
Calculates the total quantity of products stored in an object and checks whether they fit within a container limit.

### Average Calories
Calculates the average calorie intake from an array of daily records.

### Player Profile Object
Implements methods for updating a username, play time, and retrieving formatted profile information.

## Learning Outcomes

- creating and iterating over objects;
- arrays of objects;
- object methods;
- aggregating numeric data;
- working with mutable object state.
